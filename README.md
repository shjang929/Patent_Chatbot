# Hee's patent chatbot

특허 PDF의 핵심 원문 확인, AI 질의응답, 검토 메모 작성을 한 화면에서 지원하는 Streamlit 기반 애플리케이션입니다. 한국어 특허 명세서를 읽으며 관련 근거를 확인하고, 궁금한 점과 검토 내용을 기록할 수 있습니다.

## 개발 목적

특허 명세서는 분량이 길고 전문 용어가 많아 필요한 내용을 찾는 데 반복적인 탐색이 필요합니다. 발명의 개요를 파악하고 청구항과 설명을 함께 읽으려면 여러 페이지를 오가야 합니다.

이 프로젝트는 문서를 찾고, 읽고, 질문하고, 기록하는 과정을 연결하는 것을 목표로 개발했습니다. 발명의 명칭·요약서·독립항·대표도를 모아 보여주고, 자연어 질문으로 관련 원문을 찾아 내용을 이해할 수 있도록 돕습니다. 답변의 참고 원문을 직접 확인하고, 사이드바에서 추가 검색 사이트를 열거나 검토 메모를 작성할 수 있도록 구성했습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 특허 PDF 업로드 | 파일 선택 또는 끌어다 놓기로 PDF 한 개 업로드 |
| 핵심 원문 확인 | 발명의 명칭, 요약서 원문, 독립항 원문을 표시하고 요약서·독립항의 PDF 페이지 안내 |
| 대표도 확인 | 문서 앞부분에서 대표도 이미지 영역을 찾아 페이지와 함께 표시 |
| 문서 기반 질의응답 | 질문과 관련된 원문을 검색하고 Groq 모델로 한국어 답변 생성 |
| 참고 원문 확인 | 각 답변에 사용한 검색 결과와 PDF 페이지를 펼쳐서 확인 |
| 대화 기록 관리 | 업로드 문서를 유지하면서 질문·답변 기록만 삭제 |
| 특허 검색 사이트 바로가기 | 사이드바에서 KIPRIS, USPTO, Espacenet, WIPO PATENTSCOPE 열기 |
| Note 메모장 | 검토 내용과 질문을 자유롭게 작성하고 텍스트 파일로 저장 |

## 사용 흐름

1. 필요한 경우 사이드바의 특허 검색 사이트에서 문서를 찾아 PDF를 준비합니다. 바로가기는 외부 사이트를 여는 기능이며 검색 결과를 앱으로 자동 가져오지는 않습니다.
2. PDF를 업로드하고 발명의 명칭, 요약서, 대표도, 독립항을 확인합니다.
3. 하단 입력창에 질문을 입력하고 답변의 **검색된 참고 원문 확인**을 펼쳐 근거를 비교합니다.
4. 오른쪽 사이드바의 **Note**에 검토 내용을 작성하고 **파일로 저장**을 누릅니다.
5. 같은 문서로 대화를 새로 시작하려면 **질문·답변 기록 지우기**를 사용합니다.

### 메모 저장 방식

- **파일로 저장**을 누르면 앱이 실행되는 컴퓨터의 프로젝트 폴더에 `question_memo.txt`가 UTF-8 형식으로 저장됩니다. 다시 저장하면 같은 파일을 덮어씁니다.
- Windows에서는 저장 후 해당 텍스트 파일을 기본 연결 프로그램으로 여는 동작을 시도합니다.
- 입력 중인 메모는 세션에서 관리하며, 업로드된 PDF가 없는 상태에서는 초기화됩니다. 새 세션에서 저장 파일을 자동으로 불러오지는 않습니다.
- 다른 PDF로 바로 교체할 때는 메모가 자동으로 분리되거나 초기화되지 않습니다. 문서별로 보관하려면 저장한 파일을 별도 이름으로 관리하세요.
- 메모 저장은 브라우저 다운로드 기능이 아닙니다. 현재는 로컬 개인 사용을 기준으로 하며, 서버에서 실행하면 서버의 동일한 파일 경로에 저장됩니다.

| 원문 확인 | 요약서와 독립항을 생성형 요약 대신 추출한 원문으로 표시 | 실제 문구를 직접 읽고 확인 가능 |
| 문서 가독성 | PDF 좌표를 활용한 문단 구분과 줄바꿈 표시 보정 | 청구항의 긴 문장과 구성 요소를 읽기 쉽게 표현 |
| 답변 근거 확인 | 관련 발췌문을 모델에 전달하고 페이지 인용을 요청하며 참고 원문 제공 | 답변과 문서 내용을 비교할 수 있는 확인 경로 제공 |
| API 의존도 | 원문 추출과 검색은 로컬에서 수행하고 질의응답에 API 사용 | API 키 없이도 핵심 원문 열람 가능 |
| 사용 흐름 | PDF 변경 시 이전 대화 초기화, 대화 기록만 삭제하는 기능 제공 | 서로 다른 문서의 대화가 섞이지 않도록 관리 |
| 검토 내용 기록 | 사이드바 Note와 텍스트 파일 저장 기능 제공 | 문서를 읽으며 질문과 검토 내용을 기록·보관 |
| 추가 자료 탐색 | 국내외 특허 검색 사이트 4곳의 바로가기 제공 | 문서 열람 중 추가 검색 사이트에 접근 |
| 화면 구성 | 오른쪽 사이드바, 원문 카드, 한글 서체, 대화 아바타와 배경 이미지 적용 | 원문·질문·메모 영역을 구분하고 읽기 편한 화면 구성 |
| 오류 대응 | 파일 크기·페이지 수·텍스트 유무 확인 및 API 오류 안내 | 입력 문제와 서비스 오류의 원인을 파악하기 쉽게 구성 |

위 효과는 구현 방향에 따른 기대 효과이며, 처리 시간이나 답변 정확도의 정량적 개선을 측정한 결과는 아닙니다.

## 동작 방식

1. 사용자가 특허 PDF를 업로드합니다.
2. 페이지별 텍스트와 레이아웃을 분석해 핵심 원문과 대표도를 추출합니다.
3. 텍스트를 일정 길이로 나누고 TF-IDF 검색 인덱스를 생성합니다.
4. 질문과 유사한 원문을 검색해 Groq 모델에 전달합니다.
5. 모델의 답변과 검색된 참고 원문을 화면에 표시합니다.
6. 사용자가 작성한 메모는 저장 버튼을 누를 때 로컬 텍스트 파일로 기록합니다.

검색에는 문자 단위 TF-IDF와 코사인 유사도를 사용합니다. 별도의 벡터 데이터베이스나 외부 임베딩 API 없이 동작하며, 답변 생성 시에는 검색된 발췌문을 근거로 설명하도록 모델에 지시합니다.

## 실행 방법

Python 3.12 환경에서 검증했습니다. Windows PowerShell 기준으로 실행합니다.

```powershell
git clone https://github.com/shjang929/Patent_Chatbot.git
cd Patent_Chatbot
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

생성된 `.env`에 본인의 Groq API 키를 입력합니다.

```dotenv
GROQ_API_KEY=본인의_API_키
GROQ_MODEL=openai/gpt-oss-20b
```

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

브라우저에서 표시된 로컬 주소를 열고 특허 PDF를 업로드합니다. 원문 표시는 API 키 없이 가능하며, AI 질문·답변에는 API 키가 필요합니다. 질문·답변 시 질문과 검색된 문서 일부가 Groq API로 전송됩니다.

메모 내용은 현재 코드에서 AI 요청에 포함되지 않습니다. 화면의 Pretendard 서체는 외부 CDN에서 불러오며, 로딩되지 않으면 시스템 기본 서체를 사용합니다.

## 지원 범위

- 텍스트가 포함된 PDF, 최대 10MB·150페이지
- 암호화된 PDF 및 텍스트가 없는 스캔 PDF는 지원하지 않음
- 문서 형식에 따라 제목·독립항·대표도 자동 추출 결과가 달라질 수 있음
- 대표도 추출은 첫 3페이지의 대표도 표제 아래 이미지 영역을 대상으로 하며, 벡터 도면 등은 추출되지 않을 수 있음
- 독립항은 다른 청구항을 인용하는 표현의 유무를 기준으로 추출하므로 자동 분류 결과를 원문과 대조할 필요가 있음
- 어휘 유사도 기반 검색이므로 동의어나 문서 전체에 걸친 질문에서 필요한 근거를 놓칠 수 있음
- AI의 답변과 페이지 인용은 정확성이 보장되지 않으며, 제공된 참고 원문으로 확인해야 함

## 향후 개선 과제

아래 항목은 현재 구현된 기능이 아닌 후속 개발 과제입니다.

- **검색 품질 개선:** 의미 기반 검색과 재정렬을 적용해 표현이 다른 질문에 대한 검색 성능 평가
- **지원 문서 확대:** OCR 도입을 통한 스캔 PDF 지원 및 다양한 특허 문서 형식 대응
- **추출 정확도 평가:** 다양한 문서를 활용한 독립항·요약서·대표도 추출 평가 데이터 구축
- **근거 검증 강화:** 답변 내용과 인용 페이지의 일치 여부를 검증하는 절차 추가
- **문서 비교 기능:** 여러 특허의 기술 구성과 청구항을 비교하는 탐색 기능 확장
- **메모 관리 개선:** 문서별 메모 분리, 저장 파일 불러오기, 파일명 지정 및 브라우저 다운로드 지원
- **다중 사용자 지원:** 사용자별 문서·메모 저장 공간을 분리하고 서버 환경의 저장 방식 개선

## 테스트

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

API 호출은 테스트에서 모의 처리합니다. `.env`, Streamlit 비밀 설정, 임시 파일 및 로컬 샘플 PDF는 Git 업로드 대상에서 제외합니다.
